session-spoor · 猎迹 — Architecture

Agent 干活的痕迹管理系统 · MCP 双 server · 三层存储 · 一本账本 —— 插件可拔，账本不可少

三层结构 · 生命周期递进

  • • L1 涂鸦房 scratch/ —— 绑任务，结束三去向：导出 / 账本 / 蒸发
  • • L1.5 工作台 workbench/ —— 绑 agent，journal + snippet + 全文检索
  • • L2 档案房 archive/ —— 永久，版本化 sha256 寻址（契约 v0.1 起草中）
  • • 毕业路径：草稿 → 复用件 → skill，三级越来越永久

共享契约 · 多 agent 工棚

  • • mark 五值词汇表：判断 / 数据 / 坑 / 待审·自 / 待审·人
  • • SPOOR_AGENT 环境变量署名，UTF-8 任意名，不设=匿名
  • • flock 并发安全：8 进程 × 20 轮压测零丢失（Windows 退化裸写）
  • • 运行时不进 git：进 git 的只有 journal · snippet · design · STATUS

账本事件契约 v0.2 · 正式版

  • • 六类事件全前缀：workbench.new / .complete / .snippet_get · journal.write / .read / .search
  • • entry_head 前 80 字符——存在性论证 + 自毁条款（字段跟着理由走）
  • • reason 必须有真实数据来源（工具参数直通账本）
  • • hits 记条数不记内容——账本只记"发生过"，不复制正文
